This static browser editor does not contain R, WeightedTreemaps, RcppCGAL, CGAL, or a tessellation engine. It edits polygon geometry already calculated and exported by the separate Python adaptation.

## ShinyTreemaps

[ShinyTreemaps](https://github.com/m-jahn/ShinyTreemaps) is Michael Jahn's R Shiny GUI for WeightedTreemaps. It can upload tabular data, select hierarchy columns, generate Voronoi or sunburst treemaps, and customize their creation and styling. The hosted app is available at [m-jahn.shinyapps.io/ShinyTreemaps](https://m-jahn.shinyapps.io/ShinyTreemaps/).

## Method and geometry lineage

WeightedTreemaps credits Paul Murrell's 2012 work, [“Voronoi Treemaps in R”](https://www.stat.auckland.ac.nz/~paul/Reports/VoronoiTreemap/voronoiTreeMap.html), as the basis for underlying tessellation functions.

WeightedTreemaps uses [RcppCGAL](https://cran.r-project.org/package=RcppCGAL) and [CGAL](https://www.cgal.org/) for its native geometry. Geometry generated by the separate Python adaptation uses CGAL's 2D Apollonius Graph package by Menelaos Karavelas and Mariette Yvinec. CGAL components have their own licensing terms; see the [CGAL license page](https://www.cgal.org/license.html).
